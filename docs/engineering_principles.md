# Engineering Principles

1. Keep research logic separate from framework code.
2. Make experiments configuration-driven.
3. Record reproducibility metadata for every run.
4. Separate local Mac development, HPC CPU preparation, and HPC GPU execution.
5. Keep agent-readable context in the repo.
6. Add tests for core logic from day one.
7. Prefer importable placeholders over empty files.
8. Keep large artifacts and secrets out of Git.
